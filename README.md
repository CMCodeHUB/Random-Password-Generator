
# 🔐 Random Password Generator

A modern, responsive, and user-friendly Random Password Generator built using HTML, CSS, and JavaScript. Generate strong and customizable passwords with different character options and easily copy them to your clipboard.

## 🌐 Live Demo

🚀 [View Live Demo](https://random-password-generator-by-cm.vercel.app/)


## ✨ Features

- 🔐 Generate random passwords instantly
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special symbols
- 📏 Adjustable password length (4–50 characters)
- 💪 Password strength indicator
- 📋 One-click copy-to-clipboard functionality
- 📱 Fully responsive design
- 🎨 Modern gradient-based user interface
- 💻 Separate HTML, CSS, and JavaScript files

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Password generation and functionality |
| Clipboard API | Copy generated passwords |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/random-password-generator.git
```

### 2. Open the Project Folder

```bash
cd random-password-generator
```

### 3. Run the Project

Open `index.html` directly in your browser.

Alternatively, use the VS Code Live Server extension.

## 🎯 How to Use

1. Open the Random Password Generator.
2. Select your preferred password length.
3. Choose the character types you want to include.
4. Click **Generate Password**.
5. Click the copy button to copy your password.

## 📱 Responsive Design

The project is designed to work across:

- 💻 Desktop computers
- 📱 Mobile phones
- 📟 Tablets
- 🖥️ Small-screen devices

The password generator and profile card automatically adjust to different screen sizes.

## 🔒 Security Note

This project is designed for learning and everyday password-generation demonstrations.

For high-security applications, use a trusted password manager or a cryptographically secure password generator. This demo uses JavaScript's `Math.random()` and should not be relied on for generating passwords for sensitive accounts.
